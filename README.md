# 📦🤖 AI Email Agent (集装箱外贸特供版)

> 一个不会摸鱼、不会忘记规则、报价比老业务员还精明的集装箱贸易 AI 邮件助理 🚢💌

它每天的工作就是：**读邮件 → 猜意图 → 查库存 → 写回信 → 另开 AI 找茬** —— 全程无人工干预，稳如老狗，跑几千封邮件也绝不锁死数据库 😌

---

## 🧐 这玩意儿到底是干嘛的？

这是一家做集装箱全球贸易的企业。每天，客户、供应商、中介、营销机器人……什么妖魔鬼怪的邮件都往邮箱里灌。

这个项目就是一套 **AI 邮件自动分诊 + 自动化回复 + 自动业务流转系统**：

* 📬 **智能拒收**：判断这封邮件要不要回（垃圾营销邮件？中介催佣金？全网广播找货？统统 `NO_REPLY` 并在数据库留下“死因” 🙅）
* 🧠 **意图扒皮**：识别客户到底想干嘛（询价？催发票？投诉箱子坏了？要改银行账户？🚩）
* 🔍 **底牌透视**：自动去查真实的后端库存接口（不瞎编，有就是有，没有就是没有）
* ✍️ **草稿生成**：输出一封"看起来像 10 年资深业务员写的"带标准格式报价单的邮件。
* 🛡️ **交叉质检**：唤醒另一个独立的 AI 作为 Reviewer，拿着 13 条军规逐字核对，不合格直接打回重写 👮

## 🏗️ 系统架构：四阶段自动化流水线

```text
📧 新邮件入库 (API 触发或全量批处理)
    │
    ▼
🧭 Stage 1: Router 意图路由
   （识别主/次意图，决定 REPLY / NO_REPLY，并直接输出拦截诊断报告）
    │
    ▼
📚 Stage 2: Skill Aggregator 技能聚合
   （按意图加载 SOP，并去后端 API 查出真实的库存与价格）
    │
    ▼
✍️ Stage 3: Drafter 草稿生成
   （揉合全局规则 + 实体规则 + SOP + 库存数据，写出一封标准商务邮件）
    │
    ▼
🛡️ Stage 4: Reviewer 交叉审核
   （另一个 AI 拿着红线规则判卷）
    │
    ├─ ✅ PASS  → HTML 格式化 → 写入数据库，状态更新为“已生成”
    └─ ❌ FAIL  → 带着 Reviewer 的骂声，滚回 Stage 3 重新生成

```

## 🎯 系统亮点揭秘

### 1. 数据库“无痛”批处理 (Industrial-Grade Batching) 🏭

抛弃了粗暴的表级锁和死循环，采用最优雅的游标处理法：

1. `SELECT COUNT` 查出未处理总数，打印完美的进度条。
2. `for` 循环逐个击破，每次仅使用 `LIMIT 1 FOR UPDATE` 锁定单条记录。
3. 随时可以 `Ctrl+C` 掐断，支持完美断点续传，不阻塞正常业务系统的任何数据写入！

### 2. 轻量级异步 API 🔌

内置 FastAPI。正常业务系统导完邮件后，只需向 `[http://127.0.0.1:8000/api/trigger](http://127.0.0.1:8000/api/trigger)` 发送一个 POST 请求。AI 引擎会立刻在 Background Tasks 中默默开始消化邮件队列，绝不让上游服务卡顿等待。

### 3. “精明销售”心智 🧠

除了合规红线，Drafter 阶段还塞了一整套销售策略：

* 同箱型多个底价，自动挑最便宜的报给客户。
* 客户指定的堆场没货，先诚实告知，再礼貌推荐平替。
* 只要系统查到了具体库存和价格，绝对不允许 AI 敷衍回复“我们正在核实”，必须直接输出报价单。

新建 `.env` 文件，需要以下变量：

```bash
# AI 模型配置
DEEPSEEK_API_KEY=your_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com

# MySQL 数据库（存放邮件队列 e_track 表）
DB_HOST=xxx.xxx.xxx.xxx
DB_PORT=3306
DB_USER=xxx
DB_PASS=xxx
DB_NAME=xxx

# 内部 ERP/库存系统 API 接口
INVENTORY_API_URL=http://your-backend/inventory-search

```

> 💡 *注：城市、国家、箱型、颜色字典均由系统在启动时通过连接池 `requests.Session` 自动从远端拉取并缓存，告别手动维护硬编码。*

## 🚀 如何运行

在 `main.py` 中，你可以根据场景选择不同的起飞方式：

```bash
# 模式一：手动触发全量批处理 (推荐日常跑批或定时任务使用)
python -c "from main import process_all_pending_emails; process_all_pending_emails()"

# 模式二：启动 FastAPI 服务 (作为微服务随时听候 API 唤醒)
uvicorn main:app --host 0.0.0.0 --port 8000

```

*如果你想本地调教 Prompt，可以打开 `main.py` 底部的 `test_static_email()` 方法，直接粘一段邮件文本进去测，免去频繁读写数据库的烦恼。*

## ⚠️ 使用须知

* 🙅 **纯粹的销售机器**：本系统只处理集装箱**销售**，租赁/出租询价一律会被无情判定为 `NO_REPLY`。
* 🧠 **不越权承诺**：AI 没有批准付款、批准折扣、确认放箱的权限，这些核心动作的判定权永远在物理世界的同事手里。
* 🛡️ **严守风控红线**：只要涉及到银行账号变更，不管邮件写得多紧急，系统一律截停并要求独立二次确认。
